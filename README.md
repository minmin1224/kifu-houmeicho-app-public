# 寄付芳名帳

お祭りなどの寄付受付で、年度・班・芳名・寄付金額を記録し、ふくびき抽選券の配布枚数を自動計算できる個人用Webアプリです。

- インストール不要、ブラウザだけで動作します
- データはすべて端末内(localStorage)に保存され、外部サーバーには送信されません
- 芳名欄は音声入力に対応しています(Google Chrome・Microsoft Edge)
- 年度・班で絞り込んでCSV出力できます(Excelでそのまま開けます)

## 複数人で使う場合の注意

データは開いた端末・ブラウザの中だけに保存され、他の端末とは共有されません。複数の班・担当者で使う場合は、各自が自分の端末でこのアプリを使って登録し、受付終了後に各自がCSV出力したファイルを集めて1つにまとめる運用を想定しています。

## 公開URL

`index.html` がランディングページ、`app/index.html` がアプリ本体、`app/help.html` が使い方ページです。GitHub Pagesではリポジトリのルート(このファイル)がそのまま公開されます。

## ローカルでの動作確認

```
python -m http.server 8000
```

その後 `http://localhost:8000/` を開いてください。
